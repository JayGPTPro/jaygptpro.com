Install /logo-my-brand

Paste this into your terminal, or straight into Claude Code on desktop. It installs globally, so it works in every folder.

npx skills add JayGPTPro/logo-my-brand -g

This uses npx, which needs Node.js. No Node? Paste this into Claude Code instead: "Install the skill from github.com/JayGPTPro/logo-my-brand into my global skills folder (~/.claude/skills) and run its install.sh."

  1. Open Claude Code in any folder and type /logo-my-brand with your Amazon link or ASIN. Not on Amazon? Give it the brand name and one line about the business.
  2. In a few minutes you get brand.html: three options with a reason each, shown on your product, your box and page one of Amazon. Reply A, B or C, or ask for another round.
  3. The same page turns into your brand page: the chosen logo in every version, colors, fonts, five listing templates, a name check, and one zip with every file.
Honest limits: it does not clear trademarks (it checks the name and shows what it found, then search properly before you print). The product photos with your logo are previews, not photos of printed units. Built on top of logo-design by Kaan Kızıltuğ, which runs the craft checks underneath.
