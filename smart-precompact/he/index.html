תתקין לי את Smart PreCompact. תוריד את הקובץ:

התקנה של כדקה. עם ה-hook הוא מזכיר ומכין לבד, ואתה רק שולח את השורה.

מעדיף ידנית? הורד את הקובץ, גרור את התיקייה לפרויקט, והדבק ל-Claude את התוכן של install-prompt.txt.

05 / faq

שאלות שכבר שאלו.

מה ההבדל מ-/compact הרגיל? +

הקומפאקט הרגיל מסכם את כל השיחה, בלי לדעת מה הכי חשוב לך. Smart PreCompact נותן לו הוראות מה אסור לאבד, שומר את ההמשך בקובץ, ומחזיר אותו לשיחה מיד אחרי. הקומפאקט עצמו נשאר אותו /compact של Claude Code.

מה אני עושה אחרי ההתקנה? +

ממשיכים לעבוד כרגיל. כשהקונטקסט עובר 60%, Claude עונה לך, ובסוף התשובה מוסיף שורת /compact מוכנה. מעתיקים אותה ושולחים. זה הכל.

מה נשמר אצלי במחשב, ולכמה זמן? +

קובץ המשך קטן אחד לכל שיחה, בתיקייה ~/.claude/handoffs מחוץ לפרויקט. עם ה-hook, קובץ שלא נגעו בו 14 יום נמחק לבד. אין שרת ואין שליחה לשום מקום חדש. לתוך הפרויקט נכתב משהו רק אם ביקשת save במפורש.

מפתחות וסיסמאות שעלו בשיחה מוחלפים ב-[REDACTED] לפני שהוא כותב משהו. זו הנחיה ל-Claude, לא מסנן, אז הכי בטוח לא להדביק סודות לשיחה.

למה דווקא 60%? +

מספיק מוקדם כדי שיישאר מקום לסיכום טוב. הקומפאקט האוטומטי של Claude Code קורה רק כשהקונטקסט כמעט מלא, ואז כבר מאוחר. אפשר לשנות את הסף בשורה אחת.

אפשר להפעיל אותו ידנית? +

כן, בכל רגע. יש ארבעה מצבים:

/smart-precompact

מכין את השורות להדבקה. לא נכתב כלום לדיסק.

/smart-precompact handoff

שומר גם את ההמשך לקובץ, כדי להמשיך מחר בשיחה חדשה.

/smart-precompact save

מוסיף החלטות ומשימות לקבצי התיעוד שכבר קיימים בפרויקט.

/smart-precompact save notes

כמו save, וגם לתיקיית הפתקים שהגדרת ב-config.md (Obsidian וכדומה).

אפשר גם במילים: "תכין אותי לקומפאקט".

חייבים את ה-hook? +

לא. בלי ה-hook מפעילים ידנית. ה-hook מוסיף את התזכורת ב-60% ואת ההחזרה האוטומטית של ההקשר.

קומפאקט לא שורף לי usage? +

הוא עולה פעם אחת. להישאר באחוזים גבוהים עולה בכל הודעה, כי כל הודעה שולחת מחדש את כל השיחה. אחרי קומפאקט חוזרים לשיחה קטנה, והוא מחזיר את עצמו תוך הודעה או שתיים.

שני טיפים: עושים קומפאקט מיד בסוף שלב, לא אחרי הפסקה ארוכה. ואם עוברים למשימה אחרת לגמרי, /clear זול יותר.

איך יודעים שהוא באמת עובד? +

בסוף ההתקנה בדיקה אחת מראה לך שה-hook פועל וכמה הקונטקסט מלא. מאחוריו 55 טסטים אוטומטיים.

זה עובד עם כל המודלים? ובווינדוס? +

כן, בכל מקום שבו Claude Code רץ. ה-hook צריך Python 3.8 ומעלה, ופרומפט ההתקנה בודק את זה בשבילך. נבדק על Mac. בווינדוס ובלינוקס הוא אמור לעבוד, אבל עוד לא נבדק בפועל.

זה מוצר של Anthropic? +

לא. זה סקיל עצמאי של JayGPTPro, שבנוי סביב /compact של Claude Code, ולא קשור ל-Anthropic.

ממשיכים מאיפה שעצרתם. גם אחרי קומפאקט.

פרומפט אחד, דקה של התקנה, ואתה מפסיק להסביר ל-Claude שוב את מה שכבר הסברת.
