What you need. Without it, nothing happens.

The skill draws with OpenAI's image model. No OpenAI key, no images. Everything else it checks for you on the first run.

Requirements

  • Claude Code, desktop app or terminal.
  • An OpenAI API key on a verified organization. The skill uses gpt-image-2 and nothing else, and a verified org is what unlocks that model. Never connected OpenAI to Claude Code? This guide walks you through it.
  • Python 3 with the openai and Pillow packages. The first run checks for them and prints the exact install lines if anything is missing.
  • Node, only for the one-line installer.

Cost

Centsper image

A preview run of a full listing costs single-digit cents per image on your OpenAI account. The files you upload are rendered at high quality, still well under a dollar for a listing. You see every preview before you spend on the final files.

Note on size: outputs are 1024 px. Amazon accepts 1000 px and up. For a crisp zoom, upscale to 1600 or more before uploading.

Why it looks like a photo, not a filter

How it works

Install once. Then it is one line per listing.

Paste this line into Claude Code. Claude runs it, and from then on every session on your machine knows the skill.

npx skills add JayGPTPro/santa-skill -g

Works on macOS and Windows. Claude Code Desktop or the terminal, either one.

01

Type the ASIN

In any Claude Code chat, in any folder, exactly like the box at the top of this page. An Amazon URL or a folder of your own images works too.

02

Claude looks, then generates

It fetches the gallery, opens every image, decides what to transform and what to skip, and runs the images in parallel. No questions.

03

Review the sheet, upload

A before/after contact sheet with a one-line verdict per image. Pick the ones you like, swap them in for Q4, swap them out in January.
