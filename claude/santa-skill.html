What you need. Without it, nothing happens.

Same skill, same rules, two ways to draw. Claude Code uses your OpenAI API key. Codex uses its own image tool on your ChatGPT plan, so there is no key at all. Everything else each one checks for you on the first run.

Claude Code
For anyone already working in Claude Code, desktop app or terminal.
You need
  • Claude Code, desktop app or terminal.
  • An OpenAI API key on a verified organization. The skill draws with gpt-image-2, and a verified org is what unlocks that model. Never connected OpenAI to Claude Code? This guide walks you through it.
  • Python 3 with the openai and Pillow packages. The first run prints the exact install line if anything is missing.
  • Node, only for the one-line installer.
~9¢an image on your OpenAI account, one run, ready to upload.
Codex
For anyone on a ChatGPT plan. No API key, no separate bill.
You need
  • Codex, signed in with your ChatGPT account (npm install -g @openai/codex).
  • A ChatGPT plan. The images come out of your plan's usage limits, so a big catalog may take more than one session.
  • Python 3 with Pillow and opencv-python-headless. The first run checks for them.
  • Node, only for the one-line installer.
$0extra: it runs inside your ChatGPT plan.

Note on size: outputs are about 1024 px. Amazon accepts 1000 px and up. For a crisp zoom, upscale to 1600 or more before uploading.

Why it looks like a photo, not a filter

The rules are baked in. You never type them.

Ask an image model for "a Christmas version" and you get trees in a parking lot, a Santa hat on the toddler and a product that changed color. The skill carries a decade of Q4 listing experience as hard rules.

🖼️

touches the main image

Amazon wants it on pure white. The skill skips image 01 every time, no exceptions.

📦

changes the product

Same shape, color, angle, label, screen. Nothing is placed against it or on it.

👕

Faces, poses and hands stay as shot. Only a summer scene gets winter clothes, so a tank top never ends up in the snow.

🌲

A real, lit tree in any home

Outdoors gets lights, garland and a wreath. Gifts on the floor, stockings, warm light.

🎅

One hat, one adult

Never on children, never on the product, never two.

❄️

Snow where snow belongs

On the ground outside, never at a pool or on a beach: those get Christmas in the sun. No overlays, no glitter, no floating objects.

How it works

Install once. Then it is one line per listing.

Pick your tool. Paste its install line once, and from then on every session on your machine knows the skill. Works on macOS and Windows.

Claude Code
Install once: paste it into Claude Code
npx skills add JayGPTPro/santa-skill -g
Then, for every listing
/santa-skill [ASIN]

Replace [ASIN] with yours, or paste a whole list of product links. Desktop app or terminal, either one.

Codex
Install once: paste it into your terminal
npx skills add JayGPTPro/santa-skill-codex -g -a codex
Then, for every listing: start Codex and type
$santa-skill [ASIN]

Replace [ASIN] with yours, or paste a whole list. Step-by-step setup in the README.

01

Type the ASIN

In any folder: one ASIN, a product link, a whole list of them, or a folder of your own images.

02

It looks, then generates

It fetches the gallery, opens every image, decides what to transform and what to skip, and runs the images. No questions.

03

Review the sheet, upload

A before/after page with a one-line verdict per image, and one page for the whole catalog. Swap them in for Q4, swap them out in January.
