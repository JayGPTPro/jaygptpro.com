Get the skill

Install once. Then it is one line per product.

Paste this line into Claude Code. Claude runs it, and from then on every session on your machine knows the skill.

npx skills add JayGPTPro/amazon-landing-page -g

Works on macOS and Windows. Claude Code Desktop or the terminal, either one.

01

Paste the Amazon URL

In any Claude Code chat, in any folder, exactly like the box at the top of this page.

02

Claude opens the listing and builds

It reads the product page in Chrome, downloads the images, writes the page, and opens it in your browser.

03

Add your link, upload

Put your attribution link on the button, connect the email form, upload the file to your host. Done.

Before you run it

What you need. Not much.

Requirements

  • Claude Code, desktop app or terminal.
  • Chrome, connected to Claude Code. The skill reads the listing through your browser. If you already use Claude with Chrome, you are set. If not, ask Claude to connect it: it walks you through the one-time setup.
  • Node, only for the one-line installer.
Two things to do after the run

Your link. The buy button ships with the plain Amazon URL. Swap it for your attribution or affiliate link so every click is counted to you.

Your email tool. The form is wired for a field id. Paste the id from your email service and the signups land in your list.
