Takeaway · The Creative Employee

Give Your Employee Hands

Claude is not an image model. Connect one to your Claude Code employee and "make me an image" starts working. Once, three steps.

5 minutes3 stepsno coding

You need Claude Code installed, and a folder for your employee. If you ran the Character Skill, that folder already exists and this key goes in it.

Step 1 · Get a key

Create an API key in your OpenAI account

  1. Go to platform.openai.com/api-keys and sign in. This is the developer platform, a separate place from ChatGPT, even though the login is the same.
  2. Click Create new secret key.
  3. Name it after your employee, so you always know what it is. Mine says wonka.
  4. Copy the key straight away. OpenAI shows it exactly once.

A key is a credit card. Never paste it into a chat, an email or a screenshot. It goes into one file on your own machine and nowhere else.
Two things to set once. Load $5 to $10 under Billing; exploration images cost cents, so that lasts weeks. And image generation needs a one-time organization verification. Two minutes with an ID. Do both now, or step 3 will fail and you will think you did something wrong.
Step 2 · Hand it over

Paste it into one file in the employee's folder

In the folder where your employee lives, create or open a file called .env and add a single line:

# inside your employee's folder
OPENAI_API_KEY=sk-proj-your-key-here

That is the whole integration. No packages, no SDK, no settings screen. Claude Code reads the file the moment it needs the engine.

The file name starts with a dot, and that is where most people get stuck. A Mac hides dot files: in Finder press Cmd + Shift + . to show them. If your editor will not save a file with no name before the dot, let Claude Code do it. Open it in the folder and ask: create a .env file here with OPENAI_API_KEY set to the key I am about to paste.
Why a file and not the chat? Because the folder is the employee. The key sits beside his character, his skills and his memory, so every future session finds it on its own and you never paste it again.
Step 3 · Watch it work

Ask for an image

Open Claude Code in the employee's folder and ask in plain words:

> Generate a test image using the OpenAI key in .env: a red apple on a white studio background. Save it to a folder called test/.

Claude writes the small script, calls the engine and saves the file. If an apple lands in test/, your employee has hands.

Two habits that keep the bill in cents, straight from the talk. Generate at low quality while exploring and full quality only for the finalists. And always generate one image before a batch: a minute of looking catches the wrong colour before it costs you a hundred images.
If something fails

The three errors everyone hits

  • Organization must be verified. Finish the one-time verification from step 1, wait a few minutes, try again.
  • Insufficient quota. No billing credit loaded. Settings → Billing → add credit.
  • Invalid API key. Almost always a copy problem: a missing character or a stray space in .env. Create a fresh key and paste it again.
  • It says there is no key at all. The .env is in the wrong folder. It has to sit in the same folder Claude Code was opened in, next to the employee's character file.

Anything else, paste the error into Claude Code and ask it to fix the connection. Debugging its own tools is part of the job description.
