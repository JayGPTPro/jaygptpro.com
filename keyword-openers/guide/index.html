What you get

You bring one finished product video and a list of search keywords. You get one version of the video per keyword. Only the picture of the first few seconds (about 4) changes: it becomes a short AI scene that shows what that keyword names, with the keyword on screen. The soundtrack stays exactly as it was, and every version is as long as your original.

Why the opening? Sponsored Brands video starts playing without sound. The first picture and the words on it are what the shopper actually gets.

Soundtrack

New opening per keyword. Everything after the first cut, and the whole soundtrack, stays yours.

Cost: each new 5-second scene costs about $1.50 in Genrupt credits. Claude shows you the exact price and waits for your yes before it spends anything. Building the versions is free.

1

Install Claude Code

Open Terminal. Press Cmd + Space, type Terminal, press Enter.

Open PowerShell. Press the Windows key, type PowerShell, press Enter.

Never used one before? Anthropic's terminal guide shows how to open it and paste a command.

Paste this and press Enter:

Mac
curl -fsSL https://claude.ai/install.sh | bash
Windows (PowerShell)
irm https://claude.ai/install.ps1 | iex

It shows no progress while it downloads. Wait until you can type again.

These commands come from Anthropic's official install page. If anything there looks different, follow that page.

Check it worked

Close the window and open a new one. Then run:

claude --version

You should see a version number. If it says claude is not found, see Troubleshoot installation.

Sign in

claude

The first time, Claude Code asks you to log in with your Claude account. Follow the steps it shows. When you are in, type /exit and press Enter to close it for now.

On Windows, also install Git for Windows. Anthropic recommends it so Claude Code can run its usual commands.

2

Install ffmpeg and two Python packages

ffmpeg is the free tool that cuts and joins the video. numpy and Pillow are two small Python packages the skill uses to check frames and draw the title.

Mac

a. Homebrew

Homebrew installs tools on a Mac. Check if you already have it:

brew --version

If you see a version number, skip to b. If not, install it (command from brew.sh):

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

It asks for your Mac password. Nothing shows while you type; that is normal. Press Enter when it asks you to. At the end it may show a Next steps section with a few commands: copy and run them too.

b. ffmpeg

brew install ffmpeg

c. numpy and Pillow

python3 -m pip install numpy pillow

If you see an error that says externally-managed-environment, run this instead:

python3 -m pip install --user --break-system-packages numpy pillow

Check it worked

ffmpeg -version

The first line starts with ffmpeg version.

python3 -c "import numpy, PIL; print('ready')"

It prints ready.

Windows

a. ffmpeg

winget install --id Gyan.FFmpeg -e

b. Python

Already have Python 3? Skip this one.

winget install --id Python.Python.3.13 -e

Now close PowerShell and open a new one, so it finds the new tools.

c. numpy and Pillow

python -m pip install numpy pillow

Check it worked

ffmpeg -version

The first line starts with ffmpeg version.

python -c "import numpy, PIL; print('ready')"

It prints ready.

Rather not type all this? Claude Code can do this step for you. Type claude, press Enter, and paste:

Install ffmpeg, plus numpy and Pillow for Python 3, on this computer. Then check that both work.

It asks before it runs each command. Choose Yes.

3

Connect Genrupt

This connects Claude Code to your Genrupt account, so Claude can make the scenes for you. Paste this in your terminal, outside Claude Code (if Claude Code is open, type /exit first):

claude mcp add --scope user --transport http genrupt https://genrupt.com/api/agent/mcp

--scope user makes Genrupt work in every folder. Without it, it only works in the folder you ran the command from.

Sign in to Genrupt

Start Claude Code:

claude

Then type this and press Enter:

/mcp

Pick genrupt from the list and follow the sign-in steps. Your browser opens. Sign in with your Genrupt account, then come back to the terminal. If the browser does not open, copy the link Claude Code shows and open it yourself.

Check it worked

Type /mcp again. Genrupt should show as connected. Or, outside Claude Code, run:

claude mcp list

Look for the genrupt line ending in ✔ Connected. If it says Needs authentication, do the sign-in again.

5

Your first run

Get the video ready

Put your video in a folder of its own, for example on your Desktop. Give it a simple name with no spaces, like my-video.mp4.

Open Claude Code in that folder

In Terminal, type cd and a space. Drag the folder from Finder into the Terminal window. Press Enter.

Open the folder in File Explorer. Click the address bar at the top, type powershell and press Enter. PowerShell opens in that folder.

Then start Claude Code:

claude

Type your request

Copy this, then change three things: the file name, your ASIN, and your keywords. Put a semicolon between keywords.

/keyword-openers my-video.mp4, ASIN B0XXXXXXXX, keywords: hot dog roasting sticks; vegetable roasting sticks; s'mores roasting sticks

Claude Code asks before it runs commands or saves files. Choose Yes.

What happens next

  1. It reads your video. It finds your video's own cut nearest 4 seconds and checks what is in the frames it will replace. If a logo, a price or text sits there, it tells you and offers an earlier cut.
  2. It shows the scenes it will make, one line per keyword. For example: hot dog roasting sticks: a dad and his son holding two hot dogs over the same campfire. Say so if you want one changed.
  3. It shows the price and waits for your yes. Something like: 3 openings, 5 seconds each, Seedance 2.5 at 720p: 72 credits. Go? Nothing is spent until you answer.
  4. Genrupt makes the scenes, using your product photos from the ASIN.
  5. It builds every version. Seconds per version, no credits. It checks each file: same length as your original, same soundtrack, the rest of the video untouched. Then it looks at each new opening to make sure the product is yours and the title is readable.
  6. It opens a review page with your original and every version, grouped by keyword, and marks the file to upload for each one.

The videos to upload are in a folder called keyword-openers/out/upload next to your video: one mp4 per keyword, named by the keyword.

6

Upload to Amazon

In Sponsored Brands video:

  1. Make one ad group per keyword.
  2. Target that keyword on exact match, so the shopper who sees the hot dog opening is the one who typed "hot dog".
  3. Upload that keyword's version as the ad group's video.
  4. Keep your original video running on the same keywords. That is your control.
  5. After 1 to 2 weeks, compare click-through rate per keyword. Keep the openings that get more clicks. Stop the rest.

Amazon reviews every video ad before it runs.

What Amazon asks of the file

Your versions keep your original's size, frame rate and sound. If the original meets these, so do they.

Length6 to 45 seconds
Size1280x720, 1920x1080 or 3840x2160, no black bars
Frame rate23.976 to 30 frames per second
File.mp4 or .mov, H.264 or H.265, up to 500 MB
AudioAAC, PCM or MP3

Tips and fixes

  • Pick keywords that change the picture. A food, a person, a place or a use: "hot dog", "for kids", "camping". Keywords that only reorder the same words get the same scene, so skip them.
  • A moving feature needs a reference clip. For a keyword like "extendable" or "foldable", Claude asks for a short clip of the feature in use, or the AI invents how it works. A customer review video from your listing is ideal: 3 to 8 seconds, at least 300 px tall. It adds to the price, and Claude includes it in the price check.
  • The title covers the product? Ask Claude to move the title to the top or the bottom. It rebuilds in seconds and costs nothing.
  • A scene came back wrong? Tell Claude what is off. A new scene costs credits again, so it asks you first.
  • Keyword not in Latin letters? Keywords in Hebrew, Chinese, Arabic and similar scripts need an English title on screen. Ask Claude to set an English title_text for that keyword, or to turn the title off.
  • Long keyword? More than 5 words is drawn small. Ask Claude for a shorter title for that one.
  • Short video, or shot on a phone? Your video must be at least 6 seconds long (Amazon's minimum) and have a constant frame rate. Phone and screen recordings often do not. Claude warns you when it reads the video. Then ask it: Convert my video to a constant frame rate first.
  • No Genrupt? The skill still works. Drop in your own clip for each keyword (filmed, stock, or from another tool) and Claude builds the versions.
  • Stuck on any step? Open Claude Code, paste the error you see, and ask what to do.
