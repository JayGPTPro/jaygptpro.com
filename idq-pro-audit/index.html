Important

Missing Brand Story on one ASIN only

Every other listing has one. Add 3.4 stars on five reviews and four units in stock, and the most fragile listing gets named.

Titles at 199 and 200 of 200 characters

Compliant today. Truncated the day Amazon tightens the category to 150, as it already has elsewhere.

Before you run it

What you need. Two things.

Requirements

  • Claude Code, desktop app or terminal. Get it at claude.com/download.
  • Bright Data, connected to Claude Code. This is what reads the live listing. Free tier covers a normal audit. Setup below takes two minutes.
  • Node, only for the one-line installer.
What it does not see

Backend search terms. Invisible from outside. The report tells you to check your flat file.

Amazon's internal CDQ number. Needs the Hawk tool or SAS. The skill says so instead of guessing.

Pricing, Buy Box, PPC. Other tools, other reports.

Bright Data setup

Create an account at brightdata.com, open brightdata.com/cp/api_tokens and generate a token. Then pick the route that matches how you use Claude Code, replacing YOUR_TOKEN.

Route A

Claude Code desktop app

  1. Open Settings → Connectors, then Customize.
  2. Click +, choose Add custom connector.
  3. Name it brightdata, paste the URL below with your token in it.
  4. Click Add.
https://mcp.brightdata.com/mcp?token=YOUR_TOKEN

FAQ

Straight answers.

Is this the real IDQ score Amazon uses?

It scores the five public IDQ pillars the same binary way Amazon documents them. Amazon's internal CDQ number is not public, and the report says so rather than inventing one. Everything it does score comes from the live detail page.

Can I audit a competitor?

Yes. Any live ASIN on amazon.com. Auditing your top three competitors next to your own listing is the fastest way to see where you are behind on A+ depth and image count.

What if an ASIN is out of stock or region-locked?

It gets flagged as not accessible and excluded from scoring. The skill never fills in numbers it did not get.

Does it make things up?

No. If the scrape does not return a data point, for example image URLs, the report marks it unverified and says how to close the gap.

How much does a run cost?

Claude Code usage plus one Bright Data request per ASIN. A five-ASIN deep audit sits inside Bright Data's free tier.

Where did the framework come from?

The audit framework is by Ohad. Jay added category-aware title limits, mobile preview, indexing risk and cross-ASIN boilerplate detection.
