Connect Genrupt to Claude Code

Genrupt plugs in as an MCP connector. Pick whichever route matches how you use Claude Code. Both end in the same place.

Desktop app
  1. Open Settings → Connectors, then Customize.
  2. Click +, choose Add custom connector.
  3. Name it Genrupt and paste the server URL below.
  4. Click Add, then Connect, and sign in with your Genrupt account.
https://genrupt.com/api/agent/mcp
Terminal (CLI)
  1. Run the command below. The user scope makes Genrupt available in every project, not just the current folder.
  2. Open Claude Code, type /mcp, pick genrupt and choose Authenticate.
  3. Sign in with your Genrupt account in the browser window that opens.
claude mcp add --transport http --scope user genrupt https://genrupt.com/api/agent/mcp

To confirm it worked, ask Claude this. A number comes back, which means the connector is live and your credits are visible.

Two things need to exist first. If you already use Claude Code, you have both.

  2. Node.js 18 or newer, which powers the install command and the animated text renderer. Not sure? Ask Claude: Check my Node.js version and tell me if I need to upgrade. If you need it, the LTS installer is at nodejs.org. Works on macOS and Windows.
Optional: the Genrupt CLI, for your own reference files +

You do not need this. The skill takes its references from your listing through the connector you added in step two. Install the CLI only if you want to hand it your own local image or video files instead:

FAQ

Straight answers

How long does a run take? +
Plan on half an hour to an hour, almost all of it waiting on the render queue. You do not have to watch it, but leave Claude Code open so it can keep working.
Will it stop and ask me things in the middle? +
Only if the next paid action would cross the spending cap you set. That is the one interruption. Every creative decision, the hook, the mood, the camera move, the cast, the type, is made for you and explained afterwards in the report.
What comes out at the end? +
A 30 second film at 1280 by 720, three audio mixes to choose between, a style card, and an HTML report of every decision it made and every measurement it took. Version one is Amazon listing videos in 16:9 with English voiceover.
Can I run the same product more than once? +
Yes. The second run detects the first and deliberately makes a different film: different world, camera move, hook and type. Ask for the same film again instead and it will do that too. If a run breaks halfway it never pays twice either, it resumes from the last finished stage.
Mac or Windows? +
Both. The environment check prints the right install command for your machine, and Claude runs it for you.
Do I need the other Genrupt skills too? +
No. Video Autopilot only needs the connector from step two. The six genrupt-* skills cover listing images and A+ content and are separate. If you want them as well, the guide is at jaygptpro.com/genrupt-skills.
Something in my setup is broken. +
Run Run the asin-to-video-autopilot environment check in Claude Code. It prints one line per requirement with the exact fix for anything missing, and you can tell Claude to apply it. If it still will not go, email info@jaygptpro.com with the output of that check.
