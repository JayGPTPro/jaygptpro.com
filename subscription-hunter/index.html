Install the /subscription-hunter skill

Paste this into your terminal, or straight into Claude Code on desktop. It installs globally, so it's available in every folder.

npx skills add JayGPTPro/subscription-hunter -g

This uses npx, which needs Node.js (it ships with Claude Code on most setups). No Node, or the command won't run? Skip it and paste this into Claude Code instead: "Install the skill from github.com/JayGPTPro/subscription-hunter into my global skills folder (~/.claude/skills), fetch the files yourself."

  1. Download the last 12 months from your bank and your credit card as CSV files. Put them in one folder.
  2. Open Claude Code in that folder and type /subscription-hunter
  3. Read the number, then the cut list. Every cut comes with where to cancel it, every refund with a message ready to paste.

How it works, in plain words:

A small script reads your files, finds every charge that repeats, and does all the math, so the numbers are real. Claude does the judgment: what to cut, what to negotiate, what to ask you. It saves a short file next to your statements, so next month it tells you only what changed. It never logs in, never calls, never cancels. You act.

If your email is connected to Claude, it also checks your receipts to name cryptic charges and find which email each plan is on. Want files only? Add an empty file named .no-email to the folder.
