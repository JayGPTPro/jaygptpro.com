Stop Using the Same Claude Model for Everything

Fable 5.2 just launched this week. Should you switch all your work to it? Not so fast.

Claude isn't one AI. It's a team of four, and each has a different job. Using one model for everything is like sending your manager to fetch coffee.

🟢 Haiku 5.5, the intern. Simple work in bulk, fast and cheap. Tag 1,000 reviews by complaint, extract order numbers from 200 customer emails.

🔵 Sonnet 5.5, the assistant. Everyday tasks where you already know what you want. Reply to a supplier, rewrite five listing bullets, summarize a long report.

🟠 Opus 5.5, the manager. Tasks that need real thinking. Work out why your ACoS jumped, plan a launch strategy, build a Skill or a full workflow. Personally, this is the model I use about 80% of the time.

🟣 Fable 5.2, the specialist. The second opinion on your hardest problem. Opus analyzed your sales drop, but the PPC, traffic and conversion numbers still contradict each other? Ask Fable to challenge Opus's conclusions and find what it missed. It also eats your usage limit faster than Opus, so save it for those moments.

The smart move? Use the simplest model that can do the job well.

Drop a 👍 if things are a little clearer now!
