Daily Claude Hack #12

💬 It was only a matter of time.

OpenClaw showed it was possible to talk to Claude through Telegram. Now it's official.

Say hello to Channels.

Until now, Claude Code lived in your terminal. Now? You can send it tasks from your phone and come back to the computer when the work is already done.

Say you're at the park with your kids → "Run the tests and fix whatever broke."

Claude works on your computer at home and updates you when it's done.

What you can do:
→ Send tasks and bug fixes on the go
→ Ask it to read files or check logs
→ Run tests and get notified when it's done

How this is different from remote control (from the last hack):
→ /rc = enter a live session remotely
→ Channels = just send a message and Claude works

Quick setup:
1️⃣ Create a bot (Telegram or Discord)
2️⃣ Run claude channels
3️⃣ Connect the token and start writing

⚠️ Claude Code only. Computer must stay on. Setup is still a bit technical.
