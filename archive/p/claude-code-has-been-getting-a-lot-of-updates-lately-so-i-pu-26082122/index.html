Claude Code has been getting a lot of updates lately, so I pulled together a few that...

1️⃣ Design before you build
You can now use /design directly inside the Claude Code app.
Instead of building first and fixing the design later, you can ask Claude to create a few visual directions, choose the one you like, make changes, and only then start building.
Claude Design used to be a separate tool. Now much of that workflow can happen directly inside Claude Code.

2️⃣ Auto Mode is now the default
On Pro, Max, and Team, new sessions now start in Auto Mode.
Claude can keep working without asking you to approve every small action, while another model checks what it’s doing and blocks anything that looks unusual or unrelated to your request.
So you spend less time approving actions and Claude can work more independently.

3️⃣ Claude can continue after your 5-hour limit resets
If Claude Code stops because you hit your 5-hour usage limit, it can now automatically continue once the limit resets.
No need to come back later and tell it to continue.
You can turn this off under: /config → Continue automatically at usage limit

The combination of #2 and #3 is probably the most interesting part.
You can leave a longer task running, and even if it stops because of the usage limit, it can continue later without needing you there for every step.
I’d still be careful with anything critical or live.

4️⃣ Claude can now send emails and manage Google Drive
Claude can now send emails, reply to threads, and forward messages through Gmail.
In Google Drive, it can also upload, move, share, and delete files.
You connect these through Connectors, and they’re available on paid plans.

Claude Code is slowly becoming something you can give a task to and come back later to see what it got done.
