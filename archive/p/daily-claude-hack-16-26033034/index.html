Daily Claude Hack #16

⚡ Build it once. Use it forever. Meet Claude Code Skills.

If I had to pick the single most important feature in Claude Code, it's this one. If you don't know about Skills yet, today is the day.

What's a skill?
A saved set of instructions that Claude follows every time you trigger it. Think of it like a recipe card. You write it once, Claude executes it perfectly every time. No re-explaining. No repeating yourself.

Skills can do anything you'd normally ask Claude to do manually. Analyze data. Write content. Build pages. Generate reports. Review work. Create documents. Anything you do more than once becomes a one-command workflow.

How to create one:
1️⃣ Build a workflow with Claude that works well
2️⃣ Tell Claude: "save this as a skill called /my-skill-name"
3️⃣ Claude creates a file in your `.claude/skills/` folder
4️⃣ Next time, just type the slash command

Important: make sure Claude saves the skill to the right place. Skills live in `~/.claude/skills/` (global, available everywhere) or in your project's `.claude/skills/` folder (project-specific).

Two ways skills get triggered:
→ Manual: you type the /command yourself
→ Automatic: Claude recognizes when a skill is relevant to what you're asking and activates it on its own

Pro tip: you don't have to build every skill from scratch. During a conversation, ask Claude: "search for existing skills that do X" and it will find community skills you can use or adapt.

Anyone who does the same type of work more than twice. If you repeat it, skill it.
