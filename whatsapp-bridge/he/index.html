מדביקים ל-Claude Code

הוא מתקין, בונה, סוגר מראש את הפרצות שבברירת המחדל, ומתקין שומר שחוסם פקודות מסוכנות גם אם Claude שוכנע.

פרומפט התקנה
Install https://github.com/lharries/whatsapp-mcp on this computer.

1. Clone it to ~/whatsapp-mcp and install what it needs (Go, uv).
2. Before building the bridge, lock it down: listen on 127.0.0.1
   and ::1 only, refuse any request whose Host is not localhost or
   that carries an Origin header (a browser page), and never send
   .db, .env, key files or anything inside a hidden folder.
3. Build and run the bridge and show me the QR code to scan from
   WhatsApp > Settings > Linked devices.
4. Make its store folder readable only by me (chmod 700) and keep
   it out of git, Dropbox, Google Drive and iCloud.
5. Add the MCP server to Claude Code at user scope.
6. Add a PreToolUse hook to ~/.claude/settings.json that blocks any
   shell command that calls the bridge API or touches the session
   key file in its store folder, and asks me before any WhatsApp
   send tool runs. Test that it blocks.
7. Add this rule to my global CLAUDE.md: never send a WhatsApp
   message, file or voice note before showing me the exact text
   and recipient and getting my OK. Never send in bulk.
8. Tell me which of these are off on my Mac: Firewall, FileVault,
   encrypted Time Machine backups. Don't change them, I will.
9. Test it: show me my 5 most recent chats.
