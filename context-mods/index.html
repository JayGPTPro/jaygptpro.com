Questions

Good to know.

Is it free?

Yes. All three are free.

Is this an official Anthropic product?

No. These are independent mods I built for Claude Code. They are not made or endorsed by Anthropic.

Where do the buttons show up?

In the Claude Code desktop app, in one row above the chat box. In the terminal you get the buttons too, but the yellow highlight is a desktop thing.

I installed it and I don't see a button.

Mods load only in a new conversation, so open one. Still nothing? Your Claude Code version does not run mods yet: update Claude Code and open a new conversation again.

Does TL;DR use my usage?

A little. Each long reply is read once by Claude Haiku, the smallest model, through your own Claude Code. Short replies are skipped. You can turn it off with its button any time.

Does my conversation go anywhere?

Copy chat only puts text on your clipboard. TL;DR sends a long reply to Claude itself, the same account you already work with. Nothing goes to me or to anyone else.

How do I remove one?

Ask Claude to remove it, or run npx skills remove tldr-highlight -g or npx skills remove copy-chat -g. Then open a new chat.

Does it work on Windows?

I built and tested them on a Mac. The install prompt has Windows paths, and Claude adapts the steps. If something breaks, tell me in the community.
